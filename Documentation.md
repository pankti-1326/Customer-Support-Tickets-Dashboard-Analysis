# Project Documentation

## 1. Project Title

Customer Support Ticket Dashboard

## 2. Objective

The objective of this project is to analyze customer support
tickets and identify insights related to ticket volume,
team performance, response time, resolution time, and
customer satisfaction.

## 3. Dataset

The project uses customer support ticket data containing
information about ticket status, issue category, priority,
assigned team, agent, customer, and ticket resolution.

## 4. Dashboard Pages

### Page 1: Ticket Overview
Provides an overview of ticket volume, ticket status,
team-wise tickets, issue categories, response time,
and ticket channels.

### Page 2: Ticket Analysis
Analyzes monthly ticket trends, ticket priorities,
resolution hours by issue category, and customer ratings
by assigned team.

### Page 3: Agent and City Analysis
Displays city-wise ticket volume, agent performance,
and escalated tickets by issue category.

### Page 4: Problem Investigation
Provides a customer-level investigation to understand
ticket volume, response time, resolution time, and
possible relationships between these metrics.

## 5. Tools and Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
